# 电商运营助手 PRD

## 1. 文档信息

| 项目 | 内容 |
| --- | --- |
| 产品 | 电商运营助手 |
| 版本 | V1.0 MVP |
| 状态 | 开发基线 |
| 目标端 | 桌面 Web |
| 默认时区/币种 | Asia/Shanghai / CNY |
| 关联需求 | [demand.md](./demand.md) |

### 1.1 产品一句话

为电商运营团队提供围绕单品生命周期的可追溯工作台，将商品建档、竞品诊断、AI 创意、异步素材、投放建议和经营复盘串成一条可编辑、可审核的闭环。

### 1.2 产品原则

1. **单品归属**：诊断、创意、素材、投放建议和报告必须绑定同一商品及版本。
2. **人机协同**：AI 负责生成和整理，运营人员负责编辑、确认和决策。
3. **可追溯**：原始输入、AI 输出、人工修改、审批和指标变更均保留记录。
4. **可降级**：没有第三方 AI 密钥时使用模拟服务，不影响主流程演示和数据查询。
5. **不越权执行**：系统不连接广告账户，不代替用户创建广告或扣费。

## 2. 用户与场景

### 2.1 用户画像

| 用户 | 目标 | 主要痛点 | 高频任务 |
| --- | --- | --- | --- |
| 运营人员 | 快速完成单品运营准备和复盘 | 信息分散、创意产出慢、历史版本难找 | 建档、诊断、创意、数据回填 |
| 运营主管 | 控制内容和投放风险 | 审批上下文不完整、建议难追溯 | 审核素材、审批实验、看复盘 |
| 系统管理员 | 保证系统可用和数据安全 | 模型服务配置复杂、任务失败难排查 | 用户授权、服务配置、任务维护 |

### 2.2 核心场景

**新季服饰冷启动测款**：运营人员为夏季防晒衣建档并录入竞品，系统生成诊断、主图方案和视频脚本；运营人员选择素材并发起异步生成，主管审核后形成投放实验建议；7 天后录入经营数据并生成复盘，行动项进入下一轮诊断。

**数码配件爆款防守**：运营人员周期性复用商品档案，补充低价竞品及大促数据，系统输出价格和安全温控卖点建议，复盘后指导下一周期备货和定价。

## 3. 业务对象与生命周期

### 3.1 对象关系

```text
店铺 1 --- N 商品(SPU) 1 --- N SKU
                    |\
                    | N 竞品
                    | N 诊断轮次 --- N 创意方案版本
                    |                         |
                    |                         N 生成任务 --- N 素材版本
                    |                         |
                    |                         N 投放实验建议 --- N 经营数据记录
                    |                                               |
                    +-----------------------------------------------+--> 复盘报告版本
```

### 3.2 关键状态

| 对象 | 状态 |
| --- | --- |
| 商品 | 草稿、在售、停售、归档 |
| 诊断 | 生成中、已生成、生成失败、已确认、已归档 |
| 素材 | 草稿、待审核、已通过、已驳回、已归档 |
| 投放建议 | 草稿、待审批、已批准、已驳回、已结束 |
| 生成任务 | 排队中、生成中、取消中、已取消、成功、失败、已超时 |

### 3.3 任务状态流转

```text
pending -> running -> succeeded
pending/running -> cancelling -> cancelled
pending/running -> failed
running -> timed_out
failed/timed_out -> pending (人工重试，次数受配置限制)
```

取消是异步请求：第三方服务已开始计算时，系统展示“取消请求已发送”或实际取消结果，不把请求本身直接当作成功。

## 5. 页面产品需求

### 5.1 登录页

**目标**：完成身份认证并进入用户有权限的默认店铺。

**组件**：账号、密码、登录按钮、错误提示、锁定提示。

**规则**：连续 5 次失败锁定 15 分钟；会话连续 30 分钟无操作失效；登录成功后跳转到运营大盘。

### 5.2 运营大盘

**目标**：让用户在 30 秒内判断当前经营状况和待处理事项。

**内容**：

- 筛选：日期范围、平台、店铺。
- 指标卡：商品总数、在售商品数、动销率、库存预警 SKU、GMV、广告花费、CTR、CVR、ROI。
- 趋势：GMV、曝光、点击、支付订单和 ROI 按日期展示。
- 待办：库存预警、失败任务、待审核素材、待审批投放建议。
- 快捷操作：新建商品、批量导入、进入最近商品。

**交互**：点击指标卡进入对应筛选结果；待办项跳转到具体对象；无数据时显示数据范围和导入入口，而不是空白图表。

### 5.3 店铺与商品列表

**目标**：快速定位商品并进入单品工作台。

**筛选**：店铺、平台、品类、商品状态、负责人、库存预警。

**列表字段**：商品名称、主图、店铺、平台映射数、SKU 数、在售状态、库存预警数、最近诊断时间、最近复盘时间、负责人。

**操作**：新建、编辑、归档、打开工作台；归档前二次确认。归档商品只读，历史报告和审批仍可访问。

### 5.4 商品智能运营工作台

#### 5.4.1 商品档案与 SKU

- 展示商品基础信息、平台映射、SKU 规格、价格、库存和预警阈值。
- 支持编辑、保存草稿、停用和归档。
- 显示商品状态、最后修改人和时间。
- 库存低于或等于阈值时，在 SKU 行、商品页和大盘同时展示预警。

#### 5.4.2 竞品与诊断

- 竞品表格显示名称、来源平台、价格、主要参数、卖点、来源链接和采集时间。
- 点击“生成诊断”前校验商品基础信息、至少一个竞品和必要参数。
- 生成过程中显示输入快照、模型名称、耗时和状态。
- 结果按目标客群、价格带、卖点矩阵、竞品差异、转化卡点、风险和优化方向分区展示。
- 原始 AI 版本只读保存，人工修改产生新版本；支持比较两个版本。
- “确认诊断”后才能进入创意生成；归档诊断不可作为新任务输入。

#### 5.4.3 创意与脚本

- 只允许基于已生成或已确认诊断创建创意。
- 主图方案以卡片形式展示，固定显示方向、文案、卖点和视觉建议。
- 视频脚本按分镜表展示镜号、时长、画面、口播、字幕和促单话术。
- 提供编辑、复制、确认、归档和生成素材入口。
- 生成前展示所选方案版本和预计任务类型，防止错误归属。

#### 5.4.4 任务与素材库

- 任务列表显示类型、方案、提交人、服务、状态、尝试次数、开始时间、耗时和错误原因。
- 任务支持取消、失败重试和查看执行日志。
- 素材卡显示缩略图/视频封面、素材类型、版本、尺寸/时长、来源、审核状态和标签。
- 运营人员提交审核；主管批准或驳回，驳回原因必填。
- 仅已通过素材可加入投放建议。

#### 5.4.5 投放建议与审批

- 建议展示实验目标、人群、渠道、预算、出价、素材组合、A/B 变量、周期、停止条件和目标指标。
- 运营人员可编辑草稿并提交审批；提交后形成不可覆盖的版本。
- 主管在审批面板查看商品、诊断、素材和历史数据上下文后批准或驳回。
- 驳回必须输入原因；驳回后回到草稿状态并保留原审批记录。
- 批准后提供“记录外部执行”表单，不提供“立即投放”按钮。

#### 5.4.6 经营数据与复盘

- 提供按日录入、批量导入和数据修改历史。
- 基础字段输入后即时展示系统计算指标及分母说明。
- 报告生成前选择商品、实验和统计周期，展示数据覆盖范围。
- 报告包含目标/实际表格、趋势图、差异说明、数据限制和行动项。
- AI 解释使用独立标识；事实值可跳转到原始数据记录。
- 报告确认后生成只读版本，重新生成产生新版本。

### 5.5 全局任务中心

支持按商品、类型、状态、提交人和时间筛选；支持查看详情、取消和重试。任务状态变化通过轮询或事件流更新，页面显示最近更新时间。服务不可用时显示错误码和重试入口。

### 5.6 批量导入中心

流程固定为：`下载模板 -> 上传 -> 字段映射 -> 校验 -> 预览 -> 确认 -> 导入 -> 结果`。

校验结果按行显示原始行号、字段、值、错误原因。部分成功时展示新增、更新、跳过、失败四类数量，并提供失败文件下载。覆盖已有数据必须显示影响数量并二次确认。

### 5.7 审批中心

分为素材审核和投放建议审批两个标签页。每条待办展示商品、版本、提交人、提交时间、关联诊断及素材摘要。审批动作必须在服务端校验权限，并将意见写入审计记录。

### 5.8 系统管理

- 用户与角色：创建、停用、角色分配。
- 店铺授权：分配用户可见店铺和操作权限。
- 模型服务：地址、模型、密钥、超时、启用状态和连通性测试。
- 任务规则：并发数、超时、最大重试次数。
- 审计日志：按用户、动作、对象、时间和结果筛选，至少保留 180 天。

## 6. 数据字段与口径

### 6.1 商品和 SKU 必填字段

| 对象 | 字段 |
| --- | --- |
| 店铺 | 平台、店铺名称、店铺编码 |
| 商品 | 商品名称、品类、品牌、主图、在售状态、负责人 |
| SKU | SKU 编码、规格属性、销售价、可用库存、预警阈值 |
| 竞品 | 名称、平台、来源链接、价格、采集时间 |

### 6.2 经营数据字段

最小粒度：日期 + 店铺 + 平台商品，可选 SKU 和投放实验。

输入：曝光量、点击量、访客数、跳失访客数、支付订单数、销售件数、GMV、广告花费。

计算：

```text
CTR = 点击量 / 曝光量
CVR = 支付订单数 / 点击量
跳失率 = 跳失访客数 / 访客数
ROI = GMV / 广告花费
```

所有数量不得小于 0；金额以元保存两位小数；分母为 0 显示 `--`；同一数据键重复时需覆盖确认并保留变更历史。

### 6.3 AI 输出约束

- 通过服务端 Schema 校验；失败后自动修复一次，仍失败则任务失败。
- 每次调用记录模型、模板版本、耗时、业务对象和结果状态。
- 缺失字段输出“未知/数据不足”，不能编造事实。
- 绝对化宣传、虚假功效、隐私、未授权商标/肖像等内容触发风险提示。

## 7. 关键流程与异常处理

### 7.1 商品到诊断

1. 创建或导入商品及 SKU。
2. 录入竞品。
3. 生成输入快照并校验。
4. 发起诊断任务。
5. 成功后人工编辑并确认；失败后显示原因并允许重试。

### 7.2 创意到素材

1. 选择已确认诊断。
2. 生成不少于 3 组主图方案和 3 套视频脚本。
3. 编辑并确认方案版本。
4. 提交图片/视频异步任务。
5. 任务成功后进入素材库。
6. 提交审核；通过后可加入投放建议。

### 7.3 投放到复盘

1. 基于商品、诊断和已审核素材生成建议。
2. 补充实验目标和目标值并提交审批。
3. 主管批准或驳回。
4. 人工在外部平台执行并记录备注。
5. 回填或导入数据。
6. 生成、确认并导出复盘报告。
7. 将行动项转成下一轮诊断输入。

### 7.4 异常处理原则

| 异常 | 页面行为 | 数据行为 |
| --- | --- | --- |
| AI 服务不可用 | 显示服务状态、错误摘要和重试 | 保留输入快照，任务标记失败 |
| 任务超时 | 显示超时原因和重试按钮 | 保留执行尝试，不能静默丢失 |
| 文件校验失败 | 定位行和字段，允许下载错误明细 | 非法行不写入 |
| 权限不足 | 显示无权限，不泄漏对象详情 | 服务端拒绝请求并记录日志 |
| 数据不足 | 报告明确提示限制 | 不生成确定性归因 |
| 重复提交 | 禁止创建重复有效任务 | 使用幂等键记录原始请求 |

## 8. 安全、合规与审计

- 所有受保护接口均进行身份认证和服务端授权校验。
- 密码安全散列存储，模型密钥加密存储并掩码展示。
- 不保存平台明文密码、Cookie、支付凭据或会话令牌。
- 上传文件校验扩展名、MIME 类型、大小并使用随机存储名。
- 审核、审批、导入、配置和数据修改记录操作者、时间、对象、前后值和结果。
- 所有生成内容在审核前显示“AI 生成，待人工确认”。
- 系统不提供自动发布、自动投放或扣费能力。

## 9. 交付、依赖与环境

### 9.1 交付物

- 前端、后端、异步任务执行器源代码。
- 数据库迁移、初始化数据和四类导入模板。
- 离线模拟服务及语言、图片、视频服务适配器。
- API、部署、配置、备份恢复文档。
- 环境变量示例（不得包含真实密钥）。
- 自动化测试、验收测试结果和端到端演示说明。

### 9.2 外部依赖

- 可选的大语言模型服务。
- 可选的图片生成服务。
- 可选的视频生成服务。
- 数据库、任务队列和对象/文件存储。

真实服务不可用时，模拟服务应覆盖成功、失败、超时和取消，且不影响业务数据和报告功能。

### 9.3 性能目标

- 20 个并发在线用户、10,000 个商品、1,000,000 条经营记录下，普通接口 P95 <= 2 秒。
- 大盘首次加载 <= 3 秒，不计第三方模型耗时。
- 10,000 行文件校验及导入 <= 2 分钟。
- 异步状态变化 <= 5 秒反馈前端。
- 数据库每日备份，保留 7 天；任务执行器重启不得静默丢失任务。

## 10. 验收用例

| 编号 | 用例 | 通过标准 |
| --- | --- | --- |
| TC-01 | 登录和权限 | 三角色登录成功；运营人员不能审批；越权接口返回拒绝 |
| TC-02 | 商品建档 | 创建店铺、商品、3 个 SKU；库存等于阈值时出现预警 |

## 11. 版本规划

### V1.0 MVP（本文范围）

完成单组织多店铺管理、商品与竞品、AI 诊断和创意、异步任务、素材审核、投放建议、数据回填、复盘、导入、权限和审计。

### 后续候选

真实平台数据同步、竞品授权采集、广告平台只读数据接入、更多报表导出格式、移动端和多组织租户能力。以上内容不属于 V1.0 验收范围。

## 12. 变更控制

指标口径、角色权限、任务状态、外部平台范围或验收标准发生变更时，必须同时更新 `demand.md`、本 PRD 和测试用例。本文未定义的能力不作为一期强制交付项。
